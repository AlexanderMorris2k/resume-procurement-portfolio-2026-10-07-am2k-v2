# Alexander Morris Interactive Resume

A light, editorial interactive résumé for procurement and strategic sourcing recruiters and hiring leaders. Five layered sections cover Overview, Impact, Experience, Expertise, and Résumé & Contact. Achievements emphasize AI-assisted workflows and process improvement. No project imagery, illustrations, contact form, or external runtime dependencies are used.

## Use

Serve this folder with a static HTTP server or open index.html directly. All content and anchor navigation remain available without JavaScript. JavaScript adds one-section-at-a-time navigation, transitions, deep links, browser history, and keyboard controls. Use Left/Right, Home, and End while a section tab has focus. All content is included in print styles, and reduced-motion preferences disable animation.

The Gmail and LinkedIn logos link directly to Alexander's email address and LinkedIn profile. Each logo link has an accessible name and a touch target of at least 44 pixels. Logo assets are stored locally, so the page does not contact either brand's servers when it loads. The relative DOCX download serves the user's original A._Morris_New_Resume_Draft3.docx byte-for-byte unchanged. Change the dated asset query strings when replacing content to avoid stale browser caches.
