# Alexander Morris Procurement Portfolio

A self-contained static portfolio for Alexander Morris. The interface is an original, professional interpretation of the early console “blades” interaction model: five color-coded sections, layered chrome, directional navigation, keyboard support, touch gestures, and responsive layouts.

## Portfolio sections

- Home — procurement positioning, contact information, and current focus
- Impact — verified metrics and outcomes from the résumé
- Experience — chronological procurement and operations history
- Expertise — procurement analytics, contract operations, supplier performance, and process improvement
- Résumé — education, recognition, contact links, and the downloadable PDF

## Local preview

Open `index.html` directly, or serve the folder with any static HTTP server:

```text
python -m http.server 8000
```

Then open `http://localhost:8000/`.

## Files

- `index.html` — semantic five-panel portfolio
- `styles.css` — visual system, responsive layouts, reduced-motion behavior, and print styles
- `script.js` — blade navigation, keyboard controls, swipe gestures, routing, and status display
- `favicon.svg` — portfolio mark
- `resume.pdf` — downloadable two-page résumé

The site is an independent professional portfolio and does not use Microsoft or Xbox assets, trademarks, or logos.
